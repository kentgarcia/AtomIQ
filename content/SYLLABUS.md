# 🎓 AtomIQ Syllabus: From "Radiophobia" to "Nuclear Literacy"

## Overview

This comprehensive curriculum takes users from basic atomic concepts to advanced nuclear energy understanding, systematically debunking myths and building scientific literacy.

## 📝 Content Creation Guidelines

When creating new content for this syllabus:

1. **Follow the established structure**: Briefing → Myth Buster → Micro Learn → Lab → Assessment → Debrief
2. **Use credible sources**: Always cite UNSCEAR, IAEA, NEA, or peer-reviewed research
3. **Keep it engaging**: Use analogies, comparisons, and interactive elements
4. **Build progressively**: Each lesson should build on previous knowledge
5. **Debunk with evidence**: Address myths directly with data and sources
6. **Make it visual**: Include images, diagrams, and interactive simulations

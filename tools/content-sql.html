Save to repo (recommended when the editor is served via npm run content-editor): writes this database over content/database/content.db and assets/database/content.db, keeps a .bak-<timestamp> of the previous file, and bumps CONTENT_DB_VERSION in services/content-db.ts so every device refreshes its bundled copy on next launch.
Export .db just downloads the file — copy it over assets/database/content.db and bump the version yourself. Both paths run a SQLite integrity_check first. Ctrl/⌘ + S exports.

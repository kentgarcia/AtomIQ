# Google Sans Flex Font Setup

## Download Instructions

1. Visit [Google Fonts - Google Sans Flex](https://fonts.google.com/specimen/Google+Sans+Flex)
2. Click "Download family" to get all font files
3. Extract the downloaded ZIP file
4. Copy the following font files to this directory (`assets/fonts/`):
   - `GoogleSansFlex-Regular.ttf` (or `.otf`)
   - `GoogleSansFlex-Medium.ttf` (or `.otf`)
   - `GoogleSansFlex-Bold.ttf` (or `.otf`)

## Alternative: Using Static Font Files

If you can't find the exact weight files, you can:
1. Use the variable font file and extract static instances
2. Or use Google Sans (non-Flex) from [Google Fonts](https://fonts.google.com/specimen/Google+Sans)

## File Naming

Make sure the files are named exactly:
- `GoogleSansFlex-Regular.ttf`
- `GoogleSansFlex-Medium.ttf`
- `GoogleSansFlex-Bold.ttf`

The font names in the code (`constants/typography.ts`) must match these file names.
